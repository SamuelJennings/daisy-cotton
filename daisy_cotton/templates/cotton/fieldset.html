The legend names the group, not a control inside it, so a fieldset holding one control still gives that control its own c-label. With id, the description carries -description and the errors carry -errors, so a control names both in aria-describedby; without id, neither is emitted. A description or error message containing HTML is escaped; a named slot of the same name takes markup instead. A named slot filled with whitespace only still renders its element.
