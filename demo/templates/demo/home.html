A library of base daisyUI-styled components for django-cotton — buttons, inputs, cards, alerts and the rest of an application's furniture, usable in any project running Cotton and daisyUI, independent of django-mvp.

These components currently live inside django-mvp itself. This package is where they move to, so anything that only needs the components can depend on them without pulling in the rest of the application shell.

Nothing has migrated in yet — this is the born-green scaffold. The Component gallery below is already wired up and will pick up each component as it lands. It runs only in development, because it serves component source.
